## 2. Project Overview
BrightPath Youth Development Foundation is a fictional non-profit organisation created for an academic website project. The organisation focuses on youth development, digital skills, career readiness and mentorship in Limpopo.

The website is intended to provide information about the organisation and its programmes while giving visitors clear ways to volunteer, sponsor activities or make general enquiries.

## 3. Website Goals and Objectives
1. Establish a clear and professional online presence for the organisation.
2. Explain the organisation's mission, vision and programmes.
3. Provide clear calls to action for volunteering and sponsorship.
4. Make contact and enquiry information easy to find.
5. Create a responsive website that is usable on desktop and mobile devices.

## 4. Key Features and Functionality
- Responsive five-page website.
- Consistent navigation across all pages.
- Home, About Us, Programmes, Enquiry and Contact pages.
- Volunteer, sponsor and programme enquiry options.
- Front-end form validation using JavaScript.
- Two fictional contact locations.
- Image and map placeholders prepared for later development.
- Semantic HTML structure and accessible form labels.

## 5. Part 1 Scope
Part 1 includes the project proposal, content research, planning, sitemap, wireframes, basic HTML structure, navigation, initial styling, JavaScript functionality, testing preparation and GitHub repository setup.
